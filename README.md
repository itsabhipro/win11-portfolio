# Windows 11 Portfolio — Abhishek Kumar

A developer portfolio that looks and feels like **Windows 11**: desktop icons, Start menu, taskbar, acrylic windows, and **light / dark mode**.

## Features

- Desktop wallpaper + icon grid
- Start menu (pinned apps + recommended)
- Taskbar with open apps, clock, system tray style icons
- Window chrome (minimize / maximize / close)
- Light & dark theme (persisted in `localStorage`)
- Project cards with GitHub + live Vercel links where available

## Run locally

```bash
git clone https://github.com/itsabhipro/win11-portfolio.git
cd win11-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Import this repo at [vercel.com/new](https://vercel.com/new) — framework is detected as Next.js automatically.

## Stack

Next.js 14 · TypeScript · Tailwind CSS (class-based dark mode) · Lucide icons
